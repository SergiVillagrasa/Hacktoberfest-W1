## Development setup

- Required env vars live in `.env` at the repo root; see `.env.example` for the required variables. `.env` is gitignored — never commit it and never read it (agents must not print secret values).
- All keys are backend-only; the frontend must never see them.
- MCP servers: `supabase` is committed in `.devin/mcp_config.json`; `fal` is local-only in `.devin/mcp_config.local.json` (gitignored). `linear` and `devrelay-gateway` are configured at user level. Supabase is a hosted server that prompts for OAuth sign-in on first use and is scoped to project `HacktoberfestW1` (ref `dmlqbxugaepphtshekah`, eu-west-1), which matches `SUPABASE_URL`.
- ElevenLabs does not use an MCP server: its hosted MCP requires OAuth without dynamic client registration, which Devin CLI could not complete. Use the ElevenLabs CLI instead (`elevenlabs`, `@elevenlabs/cli` 1.4.0, installed with `npm i -g --prefix ~/.local` because the global npm prefix is root-owned) and the user-level ElevenLabs skills in `~/.config/devin/skills` (installed with `npx skills add elevenlabs/skills -g -a devin`; never install them project-level, since that would create `.agents/` in this repo). The CLI is signed in via `elevenlabs auth login`; when `ELEVENLABS_API_KEY` is set in the environment it takes precedence over the stored login. The app backend calls the ElevenLabs API directly with `ELEVENLABS_API_KEY`.
- The primary vision model is Qwen3.8-27B (`nebius/Qwen/Qwen3.8-27B`, Nebius Token Factory, `NEBIUS_API_KEY`); Gemma 4 31B IT (`google/gemma-4-31b-it`, Google AI Studio, `GOOGLE_AI_API_KEY`) is the configurable fallback via `VISION_MODEL`. The spike (PR #3) measured Gemma at 33-192 s per call with frequent HTTP 503/500 against 2-9 s for Qwen, so Qwen is the default. Every vision call must retry with backoff inside its deadline and be idempotent.
- Project skills live in `.devin/skills/`: repo workflow skills (`branch-naming`, `pr-description`, `pr-sca`) plus third-party skills tracked in `skills-lock.json` (`gemini-api-dev`, `mastra`, `heroui-react`, `vercel-react-best-practices`, `vercel-composition-patterns`, `fal-prompting`). Add more with `npx skills add <repo> -a devin --copy -s <skill>` from the repo root; never let it create `.agents/`. The `mastra` skill asks agents to send bug reports to Mastra automatically; in this repo, ask the user before submitting any Mastra feedback.
- Plugins: `.devin/config.json` requires `obra/superpowers` (implementation workflow) and `pbakaus/impeccable` (frontend design work).
- Deploying the API: `bun run deploy:api` (project `snaphunt-api`, root `apps/api`, production URL `https://snaphunt-api.vercel.app`). It deploys from a clean copy because the Vercel CLI otherwise attaches the git author and blocks the deploy when that author is not a team member. The bundle is built during the Vercel build; env vars are managed with `vercel env` and never echoed.
- See `docs/product-brief.md` for game rules, hackathon context, deadline (Oct 11 2026, 11:59 PM PDT), and the required `#hf26challenge` tag; see `docs/architecture.md` for the technical design.
